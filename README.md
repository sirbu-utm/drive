# DRIVE1

Одиночный автосимулятор в открытом мире: Godot 4.7, собственная физика машины и фотореалистичный визуал.
Первая машина — Koenigsegg CCGT. Ботов и мультиплеера нет.

## Что уже есть
- **Физика** (`game/scripts/vehicle/`): шины Pacejka с комбинированным скольжением и relaxation length, подвеска на ShapeCast со стабилизаторами, трансмиссия (секвентальная 6-ступка, LSD, сцепление), аэродинамика, ABS/TCS/ESC. 30 headless-тестов: разгон 0–100 за 3.45 с, тормозной путь 100–0 — 32 м, максималка 316 км/ч, скидпад 1.3 g, дрифт.
- **Машина**: конвейер в Blender (`pipeline/build_car.py`) раскладывает модель по материалам и ставит колёса в арки. Шейдеры: краска с хлопьями и лаком, карбон, стекло, фары и стопы, накал тормозных дисков.
- **Мир 4×4 км** (`pipeline/world/`, `game/scripts/world/`): рельеф на Terrain3D, кольцевая дорога ~10 км с прямой, горный серпантин, аэродром, грунтовая петля, океан. Дороги — меши с процедурной разметкой и отбойниками. Деревья — импосторы, запечённые в Cycles из моделей Poly Haven (~80 тыс. деревьев).
- **Небо**: время суток по реальным HDRI-снимкам (серия qwantani), солнце восстановлено по самим снимкам.

## Запуск
1. Godot **4.7.2** (Forward+). Проект лежит в папке `game/`.
2. Главная сцена — `scenes/game.tscn` (в разработке). Мир без машины: `scenes/world/world_preview.tscn`. Тестовая площадка: `scenes/test_track.tscn`.

## Пересборка ассетов (WSL + Windows)
- Машина: `scripts/build_car.sh` (Blender 4.5 в `tools/blender`).
- Деревья: `scripts/bake_vegetation.sh` (исходники Poly Haven качает `pipeline/fetch_polyhaven.py` в `assets_src/`).
- Мир: `scripts/build_world.sh` (Python venv с numpy, scipy и pillow + Godot headless).
- Тесты физики: `scripts/test.sh`.
