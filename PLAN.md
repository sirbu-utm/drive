# DRIVE1: план разработки

Одиночный open-world автосимулятор (жанр «фестивальных» аркадно-симуляторных гонок). Без ботов и мультиплеера.
Главное: **визуал** и **физика управления**. Первая машина: Koenigsegg CCGT (модель лежит в `assets_raw/`).
Это нативное Windows-приложение (.exe), а не веб.

Роли: **Opus** пишет план и проверяет каждую фазу, **Sonnet-агент** пишет весь код и ассеты.

## 1. Стек (решение принято)

| Что | Чем | Почему |
|---|---|---|
| Движок | **Godot 4.x stable** (последняя стабильная, совместимая с Terrain3D), рендер **Forward+ / Vulkan** | Бесплатный, без логинов, полностью управляется из CLI, сцены и скрипты в тексте, хороший рендер (SDFGI, SSR, SSAO/SSIL, volumetric fog, glow), экспорт в .exe |
| Физика твёрдых тел | **Jolt Physics** (встроен в Godot 4.4+) | Стабильные столкновения на высокой частоте тиков |
| Физика машины | **своя**, на GDScript поверх RigidBody3D | Управление — главная фича, поэтому никаких VehicleBody3D |
| Террейн | аддон **Terrain3D** (GDExtension, MIT); запасной вариант — свой чанковый террейн с HeightMapShape3D | Clipmap-LOD, текстурирование, коллизии, инстансер растительности |
| Обработка ассетов | **Blender 4.x portable** (zip, headless Python) | Разбивка модели на материалы, расстановка колёс, экспорт в GLB, превью-рендеры в Cycles для проверки |
| Ассеты | **Poly Haven / ambientCG** (CC0): HDRI, PBR-текстуры асфальта/травы/скал, модели растений | Реалистичный визуал без лицензионных проблем |
| Звук | синтез сэмплов офлайн (Python, при необходимости numpy в venv) + кроссфейд по RPM в Godot | Нет лицензий, звук полностью под контролем |

Инструменты лежат в `tools/` (в .gitignore): `tools/godot/`, `tools/blender/`.
Все лицензии сторонних ассетов и аддонов записываются в `CREDITS.md`.

## 3. Фазы

Каждая фаза кончается **проверяемым результатом**: скриншоты/рендеры в `docs/shots/phaseN/`, метрики в `PROGRESS.md`, локальный git-коммит. Opus принимает фазу, только посмотрев рендеры и цифры.

1. Скачать Godot 4.x stable win64 (версия `editor` + `_console.exe`) через GitHub API. Версию выбрать по совместимости с последним релизом Terrain3D.
2. Скачать Blender 4.x portable (windows-x64 zip) с download.blender.org.
3. `git init`, `.gitignore` (tools/, .godot/, build/, *.tmp).
4. Godot-проект `game/`: Forward+, Jolt, `physics_ticks_per_second = 240`, `max_physics_steps_per_frame = 8`, окно 1920×1080, vsync. Структура: `game/scenes`, `game/scripts/{vehicle,camera,world,ui,audio,core}`, `game/assets/{cars,textures,hdri,audio,vegetation}`, `game/tests`.
5. Скрипты автоматизации в `scripts/` (bash):
   - `godot.sh` — запуск console-exe с правильными Windows-путями;
   - `import.sh` — `--headless --import`;
   - `test.sh` — headless-тесты (`--headless --script` или тестовая сцена с `--quit-after`), exit-код ≠ 0 при провале;
   - `shot.sh <scene> <out.png> [frames]` — скриншот через Movie Maker (`--write-movie out.png --fixed-fps 60 --quit-after N`) или через скрипт, который сохраняет viewport в PNG. Рендер на GPU, окно может мелькнуть — это нормально.
6. Проверка: пустая сцена с небом рендерится в PNG, в логе дискретная карта RX 7800 XT.

### Фаза 1 — Конвейер модели машины (Blender headless)
Скрипт `pipeline/build_car.py` (запуск `blender.exe -b -P ... -- args`) делает всё повторяемо:
1. Импорт трёх OBJ с правильными осями. Перевести в «перёд = −Z в Godot» (или +Z по `MODEL_FRONT`, но выбрать один вариант и записать в `PROGRESS.md`). Origin: по центру между осями, на уровне земли при статической посадке.
2. Разбить кузов на loose parts и классифицировать по эвристикам + `pipeline/material_overrides.json` (ручные правки по индексу/bbox части). Материалы: `paint` (кузов), `carbon` (низ, диффузор, сплиттер, пороги, зеркала-основание), `glass` (лобовое, боковые), `headlight_glass`, `headlight_chrome`, `taillight` (emissive, отдельная поверхность для стопов), `black_plastic`, `interior`, `chrome/metal`, `exhaust`.
3. Колёса: найти центры арок (кольцевой вырез в оболочке), поставить 4 колеса, правый борт зеркалить с исправлением нормалей. Разделить на `rim`, `tire` (резина + боковина), `brake_disc`, `caliper`. Pivot каждого колеса в центре ступицы. Суппорт — отдельный узел, который **не вращается** вместе с колесом (если в модели суппорта нет — сделать простой).
4. Сглаживание нормалей (auto smooth / weighted normals), удалить дубликаты, проверить, что полигоны смотрят наружу.
5. Сгенерировать UV (Smart UV Project) хотя бы для карбона и шин, чтобы работали текстуры.
6. Экспорт `game/assets/cars/ccgt/ccgt.glb` с иерархией: `CCGT` → `Body`, `Wing`, `Wheel_FL/FR/RL/RR` (+ `Caliper_*`), `Headlight_L/R` (маркеры для SpotLight), `Taillight_*`, `Exhaust_L/R` (маркеры), `Mirror_L/R`. Плюс `ccgt_meta.json`: позиции колёс, радиус, ширина, колея, база, bbox.
7. Превью в **Cycles** (GPU/HIP, если не заводится — CPU), HDRI-освещение: вид 3/4 спереди, сбоку, 3/4 сзади, сверху, плюс «карта классов» с яркими цветами по материалам. Сохранить в `docs/shots/phase1/`.

**Приёмка:** на рендерах колёса стоят точно в арках, все 4 повёрнуты лицом наружу, стекло прозрачное, фары и фонари на месте, краска не «залезает» на стекло и карбон.

### Фаза 2 — Физика управления (главная фича)
`game/scripts/vehicle/`: модули `vehicle.gd` (RigidBody3D), `wheel.gd`, `tire_model.gd`, `drivetrain.gd`, `aero.gd`, `assists.gd`, `vehicle_params.gd` (Resource, все цифры тут), `input_filter.gd`.

**Модель:**
- Шасси: RigidBody3D с явным центром масс и тензором инерции (не из коллайдера). Коллайдер: convex hull по упрощённому кузову + низ.
- Подвеска: 4 колеса на **ShapeCast3D** (сфера или цилиндр, а не тонкий луч — так мягче проходятся стыки и бордюры). Пружина + демпфер с раздельными bump/rebound, отбойник (прогрессивная жёсткость в конце хода), стабилизаторы поперечной устойчивости спереди и сзади. Ход подвески и статическая посадка из params.
- Шины: **Pacejka Magic Formula** (B, C, D, E) отдельно по продольной и боковой силе; комбинированное скольжение через нормированный вектор скольжения (friction ellipse); load sensitivity (μ падает с нагрузкой); **relaxation length** для боковой силы (убирает дрожание на малых скоростях); на очень малой скорости — переход к модели «пружина-демпфер статического трения», чтобы машина стояла на склоне и не ползла. Поверхность: асфальт / бордюр / трава / гравий / грязь с разными μ и сопротивлением качению (по physics material или группе коллайдера).
- Каждое колесо — отдельная степень свободы вращения (ω, момент инерции), интегрируется на каждом физическом тике 240 Гц (при необходимости сабстеппинг ×2–4 только для колёс).
- Трансмиссия: кривая крутящего момента двигателя (таблица RPM → Nm) + торможение двигателем, инерция маховика, сцепление (для старта и переключений), **6-ступенчатая секвентальная** КПП со временем переключения ~60–80 мс (обрезка тяги), главная пара, **LSD** (преднатяг + коэффициенты на тяге/сбросе), привод задний. Режимы: авто и ручная (+ авто-сцепление). Отсечка с мягким rev-limiter.
- Тормоза: момент на каждое колесо, баланс перед/зад, ручник (только задние, с блокировкой).
- Аэродинамика: сопротивление (CdA), прижимная сила спереди/сзади в разных точках (баланс зависит от скорости), прижим антикрыла приложен в точке крыла. Сопротивление качению.
- Рулевое управление: Акерман, максимальный угол колёс ~32°, на скорости угол ограничивается (для клавиатуры), плавное возвращение. Для геймпада — аналог с настраиваемой линейностью и мёртвой зоной.
- Ассисты (каждый вкл/выкл в настройках): ABS, TCS, ESC (стабилизация), помощь контрруля (только для клавиатуры). По умолчанию: ABS вкл, TCS вкл, ESC выкл.
- Ввод: клавиатура (WASD/стрелки, Space — ручник, Shift/Ctrl или E/Q — передачи, C — камера, R — сброс на дорогу, F1 — телеметрия), геймпад (XInput через Godot Input: стики, курки как аналог газа и тормоза).

**Параметры CCGT (стартовые, тюнинг по тестам):** масса ~1100 кг, развесовка 42/58, ЦМ ~0.40 м над землёй, атмосферный V8 5.0 л ~450 кВт @ 8500 об/мин, отсечка 9000, пик момента ~560 Нм @ ~6500, база и колея из `ccgt_meta.json`, радиус колеса 0.3225 м. Передачи примерно 2.92 / 2.13 / 1.67 / 1.35 / 1.13 / 0.96, главная пара ~3.5. CdA ≈ 0.75 м², ClA ≈ 2.2 м² (баланс прижима ~40/60). Пиковый μ шин ~1.3 (полуслики).

**Телеметрия (F1):** скорость, RPM, передача, по каждому колесу — нагрузка, slip ratio, slip angle, ход подвески, сила; диаграмма g-g; график в реальном времени. Нужна для тюнинга, в релизе выключена.

**Headless-тесты** (`game/tests/vehicle_tests.gd`, прогоняются через `scripts/test.sh`, результаты в `PROGRESS.md`). Каждый тест — сценарий на плоской тестовой площадке с программным вводом:

| Тест | Цель |
|---|---|
| Стоит на месте 10 с на ровном и на склоне 15° с ручником | дрейф < 2 см, нет дрожания |
| 0–100 км/ч (с TCS) | 3.0–3.6 с |
| 0–200 км/ч | 9–12 с |
| Максимальная скорость | 310–330 км/ч, на прямой нет рыскания и колебаний |
| Торможение 100–0 (с ABS) | 30–35 м, машина держит прямую |
| Круг постоянного радиуса R=60 м | 1.1–1.4 g, без внезапного срыва |
| Слалом / смена полосы на 120 км/ч | не разворачивает при ESC вкл; при ESC выкл — управляемая избыточная поворачиваемость |
| Сброс газа в повороте | лёгкая избыточная поворачиваемость, без мгновенного разворота |
| Дрифт (TCS выкл, газ + руль) | устойчивый занос, ловится контррулём |
| Прыжок с трамплина | приземление без «взрыва» физики, подвеска отрабатывает |

Тестовая сцена `scenes/test_track.tscn`: большая плоскость, трамплин, бордюры, склон, скидпад-разметка. В ней же можно ездить вручную.

**Приёмка:** все тесты зелёные, цифры в таблице `PROGRESS.md`, плюс короткая серия кадров (Movie Maker) скидпада и дрифта.

### Фаза 3 — Мир
Открытая карта ~4×4 км, генерируется офлайн (tool-скрипт), а в рантайме только грузится:
1. **Рельеф**: heightmap (fbm-шум + domain warp + эрозия-подобное сглаживание), горы с одной стороны, холмы и долина, побережье/озеро. Импорт в Terrain3D. Текстурирование по наклону и высоте: трава, сухая трава, земля, скалы, песок (PBR с Poly Haven, 2K).
2. **Дороги**: сплайны (Curve3D) из JSON: (a) кольцевая трасса ~8–12 км вокруг карты, (b) горный серпантин, (c) скоростная прямая ≥3 км для максималки, (d) аэродром/площадка для дрифта. Меш дороги генерируется вдоль сплайна: асфальт PBR + разметка шейдером по UV, обочины, бордюры на поворотах, отбойники в опасных местах. Рельеф под дорогой выравнивается (поправка heightmap вдоль сплайна с плавным переходом). Коллизия дороги — отдельные trimesh-чанки.
3. **Небо и время суток**: PhysicalSkyMaterial или своя небесная шейдер-модель + солнце (DirectionalLight3D, 4 каскада PSSM) + луна и звёзды; цикл дня, настраиваемый; объёмный туман на рассвете. HDRI-вариант для фото-режима.
4. **Растительность**: деревья и кусты (модели с Poly Haven, если нет — Blender-генерация) через MultiMesh по чанкам, visibility range + fade, импосторы на дальних дистанциях. Трава — инстансинг вокруг камеры с шейдером ветра. Плотность от настроек качества.
5. **Вода**: озеро/море — шейдер с нормалями, отражениями (SSR) и пеной у берега.
6. Немного рукотворного: трибуны/ворота у старта, дорожные знаки, столбы — простые модели.
7. Респаун: R — на ближайшую точку дороги по направлению движения.

**Приёмка:** 6–8 скриншотов (рассвет, полдень, закат, ночь с фарами; серпантин, прямая, озеро, вид сверху) + замер FPS.

### Фаза 4 — Визуал и ощущения
1. **Краска**: свой spatial-шейдер: base color + металлические хлопья (процедурный шум в object space, без UV), clearcoat (CLEARCOAT/CLEARCOAT_ROUGHNESS), френель. Выбор цвета в меню. Карбон — текстура плетения с анизотропией. Стекло — прозрачное с отражениями и лёгкой тонировкой. Шины — резина с боковиной.
2. **Отражения**: SSR + sky radiance; опционально ReflectionProbe, следующий за машиной (Ultra).
3. **Свет машины**: фары — SpotLight3D с тенями (вкл автоматически ночью или по кнопке L), ДХО emissive; стоп-сигналы ярче при торможении; задний ход.
4. **Постобработка** (WorldEnvironment + CameraAttributes): тонмаппинг AgX/ACES, автоэкспозиция, glow/bloom, SSAO, SSIL, SSR, SDFGI (High/Ultra), volumetric fog, цветокоррекция (LUT), виньетка; DOF в фото-режиме. **Motion blur** через CompositorEffect (можно взять готовый open-source аддон под MIT, если совместим). Сглаживание: MSAA 4x + screen-space AA (TAA опционально, следить за ghosting на скорости).
5. **Частицы и следы**: дым шин (GPUParticles3D, плотность от проскальзывания), пыль и трава на грунте, искры при ударе снизу, следы шин (динамические ленточные меши-декали, кольцевой буфер), выхлоп/отстрелы на сбросе при высоких оборотах.
6. **Камеры** (C — переключение): погоня ближняя и дальняя (пружинное следование, FOV растёт со скоростью, лёгкая тряска от дороги и скорости, взгляд по углу заноса), капот, бампер, кокпит, свободный орбит мышью/стиком. **Фото-режим** (P): пауза физики, свободная камера, FOV, DOF, экспозиция, время суток, сохранение скриншота в высоком разрешении.
7. Пресеты графики Low/Medium/High/Ultra, масштаб рендера / FSR2.

**Приёмка:** серия «журнальных» кадров машины (3/4 спереди на закате, в движении с motion blur, дым при дрифте, ночь с фарами) + сравнение Low и Ultra.

### Фаза 5 — Звук, интерфейс, режимы, сборка
1. **Звук двигателя**: офлайн-синтез (Python) лупов V8 (порядок работы цилиндров, гармоники, впуск/выпуск) на 6–8 значениях RPM × (газ / сброс). В Godot кроссфейд + pitch по RPM, слои: впуск, выхлоп, трансмиссия, отсечка, отстрелы. Шины: визг по slip, шорох по поверхности, ветер по скорости, удары подвески, переключения. 3D-позиционирование для внешних камер, отдельный микс для кокпита.
